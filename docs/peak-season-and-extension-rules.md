# 성수기 및 연장 시간 규칙

## 🔴 성수기 특별 규칙

### 1. 반납시간 고정

#### 규칙
- **성수기에는 반납시간이 자동으로 고정됩니다**
- 반납시간 = **대여시간 - 1시간**
- 사용자가 수정할 수 없음

#### 예시

| 대여시간 | 반납시간 (성수기) | 대여 기간 |
|---------|-----------------|---------|
| 10:00   | 09:00 (전날)    | 23시간  |
| 15:00   | 14:00           | 23시간  |
| 08:00   | 07:00 (전날)    | 23시간  |

### 2. UI 표시

**반납시간 입력 필드 - 성수기일 때:**

```
┌─────────────────────────────────────┐
│ 반납시간                             │
├─────────────────────────────────────┤
│ 14:00 (자동 고정)                   │
│                                     │
│ ⚠️ 성수기 반납시간은 고정입니다.    │

│                                     │
│ [ 배차 문의하기 ]                   │

```

### 3. 메시지

```
"성수기 반납시간은 고정입니다. 배차 당일 문의가 가능합니다."
```

### 4. 배차 문의 링크
- 버튼/링크: "배차 문의하기" 또는 "당일 배차 문의"

  - 관리자 연락처 (전화번호, 카카오톡, 문의 폼)
  - 또는 실시간 채팅

## 🚨 배차 시간대별 반납시간 고정

### 11:00 ~ 14:00 배차 특별 규칙

**11시부터 14시 사이에 배차되는 차량은 반납시간이 10:00으로 고정됩니다.**

#### 규칙
```
배차 시간대가 11:00 ~ 14:00 → 반납시간 = 10:00 (당일)
```

#### 예시

| 배차 시간 | 대여 시간 | 반납 시간 | 대여 기간 |
|----------|----------|----------|---------|
| 11:30    | 11:30    | 10:00    | 22.5시간 |
| 12:00    | 12:00    | 10:00    | 22시간  |
| 14:00    | 14:00    | 10:00    | 20시간  |
| 14:15    | 14:15    | (자유선택) | (일반규칙) |

#### UI 표시

```
┌─────────────────────────────────────┐
│ 대여 시간: 12:00                    │
│ 반납 시간: 10:00 (배차 당일)        │
│                                     │
│ ℹ️ 11:00~14:00 배차 차량은          │
│ 당일 10:00 반납입니다.              │
└─────────────────────────────────────┘
```

## ⏱️ 연장 시간 비용 규칙

### 핵심 규칙: 1~2시간 연장은 2시간 요금

```
연장 시간이 1시간 또는 2시간 → 2시간 연장료 청구
연장 시간이 3시간 이상 → 실제 연장 시간 요금 청구
```

### 상세 계산

#### Case 1: 1시간 연장
```
기본 대여: 24시간
실제 사용: 25시간 (1시간 초과)

연장 시간: 1시간
계산: 1시간 < 2시간 → 2시간 요금 적용

평일 기준: 7,000원/시간 × 2시간 = 14,000원
```

#### Case 2: 2시간 연장
```
기본 대여: 24시간
실제 사용: 26시간 (2시간 초과)

연장 시간: 2시간
계산: 2시간 = 2시간 → 2시간 요금 적용

평일 기준: 7,000원/시간 × 2시간 = 14,000원
```

#### Case 3: 3시간 연장
```
기본 대여: 24시간
실제 사용: 27시간 (3시간 초과)

연장 시간: 3시간
계산: 3시간 > 2시간 → 실제 시간 요금 적용

평일 기준: 7,000원/시간 × 3시간 = 21,000원
```

#### Case 4: 4시간 연장
```
연장 시간: 4시간 > 2시간 → 4시간 요금

평일 기준: 7,000원/시간 × 4시간 = 28,000원
```

### 요금표 예시

| 연장 시간 | 평일 | 주말 | 성수기 |
|----------|------|------|--------|
| 1시간    | 14,000원 | 16,000원 | 18,000원 |
| 2시간    | 14,000원 | 16,000원 | 18,000원 |
| 3시간    | 21,000원 | 24,000원 | 27,000원 |
| 4시간    | 28,000원 | 32,000원 | 36,000원 |

## 💻 백엔드 계산 함수 (Python)

### 1. 반납시간 자동 계산

```python
from datetime import datetime, timedelta

def calculate_return_time(
    rental_start_time: time,
    is_peak_season: bool,
    rental_start_date: date
) -> tuple[time, str]:
    """
    성수기 또는 배차 시간대별 반납시간 자동 계산
    
    Returns:
        (return_time, message)
    """
    
    # 11:00 ~ 14:00 배차 차량은 10:00 반납
    if datetime.strptime(rental_start_time, "%H:%M").time() >= datetime.strptime("11:00", "%H:%M").time() and \
       datetime.strptime(rental_start_time, "%H:%M").time() <= datetime.strptime("14:00", "%H:%M").time():
        return "10:00", "11:00~14:00 배차 차량은 당일 10:00 반납입니다."
    
    # 성수기: 반납시간 = 대여시간 - 1시간
    if is_peak_season:
        rental_dt = datetime.combine(rental_start_date, rental_start_time)
        return_dt = rental_dt - timedelta(hours=1)
        return return_dt.time().strftime("%H:%M"), "성수기 반납시간은 고정입니다. 배차 당일 문의가 가능합니다."
    
    # 일반 규칙: 반납시간 자유 (기본값은 대여시간 + 24시간)
    return None, None
```

### 2. 연장 시간 비용 계산

```python
def calculate_extension_fee(
    extension_hours: float,
    hourly_rate: int,
    peak_season: bool = False
) -> int:
    """
    연장 시간 비용 계산
    
    규칙:
    - 1시간 <= 연장시간 <= 2시간: 2시간 요금
    - 연장시간 > 2시간: 실제 시간 요금
    """
    
    # 연장 시간이 없으면 0
    if extension_hours <= 0:
        return 0
    
    # 1시간 또는 2시간이면 2시간 요금 청구
    if extension_hours <= 2:
        return hourly_rate * 2
    
    # 3시간 이상은 실제 시간 요금
    return int(hourly_rate * extension_hours)


# 사용 예시
extension_hours = 1.5  # 1시간 30분
hourly_rate = 7000     # 평일 시간당 요금

fee = calculate_extension_fee(extension_hours, hourly_rate)
print(f"연장 요금: {fee}원")  # 출력: 연장 요금: 14000원
```

### 3. 전체 가격 재계산

```python
def recalculate_total_price(
    base_price: int,
    base_hourly_addition: int,
    insurance_total_price: int,
    actual_return_time: time,
    standard_return_time: time,
    hourly_rate: int
) -> dict:
    """
    반납시간 변경 시 전체 가격 재계산
    """
    
    # 연장 시간 계산
    extension_minutes = (
        datetime.combine(date.today(), actual_return_time) - 
        datetime.combine(date.today(), standard_return_time)
    ).total_seconds() / 60
    
    extension_hours = extension_minutes / 60
    
    # 연장 요금 계산 (새 규칙 적용)
    new_hourly_addition = calculate_extension_fee(extension_hours, hourly_rate)
    
    # 새로운 총합계
    new_total_price = base_price + new_hourly_addition + insurance_total_price
    
    return {
        'extension_hours': extension_hours,
        'extension_fee': new_hourly_addition,
        'total_price': new_total_price,
        'changed': new_hourly_addition != base_hourly_addition
    }
```

## 🔄 가격 변경 플로우

### 반납시간 수정 시

```
사용자가 반납시간 변경
         ↓
연장 시간 계산
         ↓
연장 시간별 요금 규칙 적용
    1~2시간 → 2시간 요금
    3시간 이상 → 실제 시간
         ↓
총 가격 재계산
         ↓
화면 업데이트
```

### 예시 시나리오

```
기본 설정:
- 대여시간: 12:00 (당일)
- 반납시간: 12:00 (다음날) → 기본값
- 렌트료: 70,000원 × 1일 = 70,000원

사용자가 반납시간을 13:30으로 변경:
- 연장 시간: 1시간 30분
- 규칙 적용: 1.5시간 < 2시간 → 2시간 요금!
- 연장료: 7,000원 × 2시간 = 14,000원
- 보험료: 40,000원 (1일)
- 합계: 70,000 + 14,000 + 40,000 = 124,000원 ✓
```
